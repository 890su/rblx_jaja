# Meteor Rush — Marketing & Promotion

Plan: `docs/04-marketing-plan.md`. Feature facts: `docs/01-game-design.md` (never promise what the game doesn't do).

## Positioning
Hook: "Every second you get faster. Run to the edge of the crater, grab the rarest meteor, and don't get robbed on the way home." Emotions: speed rush, "1 in 2,000!" reveal, chase drama.
Never: copy leaders' titles/thumbnails/models, use "Steal a ___", brainrot framing, "free Robux", implied affiliation.

## Store page rules
- 3–4 thumbnail variants always live in Thumbnail Personalization; replace loser every 2 weeks.
- No clickbait the first 60 s can't deliver (bounce < 60 s is a top Home signal).
- Video 30 s: 0–3 s speed counter, 3–15 s rare grab + chase, 15–30 s hatch + income.
- Seasonal tag in title only during events: "[❄️ WINTER] Meteor Rush".

## Short-form content pillars
Chase clips · Rarity reveals · Speed escalation timelapse · Shower chaos · Update teasers (Thu/Fri). Game name in first frame. 1 post/day target, 3/week minimum.
Script format: `Hook (0–2s) | Beat (3–10s) | Payoff (10–20s) | CTA ("Meteor Rush on Roblox")`, + caption, + hashtags (≤ 5).

## Weekly comms cadence
Mon recap · Wed midweek event ping · Fri teaser + new code · Sat Starfall + update notes. Codes expire in 7–14 days.
Patch notes format: headline, 3–5 bullets (new / changed / fixed), new code, "You asked, we shipped" item.

## Creators
Targets 5k–200k subs, simulator/obby niche. Offer early access, creator code, creature naming. Wave 1 = launch week 2; wave 2 = after Dec 21 decision. Disclose sponsorships; no misleading content.

## Compliance
No rewarded ads/watch-to-earn for < 13; Discord is 13+; never collect personal data from minors; accurate metadata.

## Measuring
Per thumbnail: PTR + bounce bands. Per creator: code redemptions. Ads: cost per play, stop if ad cohorts bounce worse than organic.
