Публикация обновляет место в текущем режиме доступа. Она не является подтверждением полной приёмки8 игроков, реальных платежей, shutdown/rejoin, сетевой задержки и мобильной производительности. Ограничения отражены в preprod/chase отчётах. Облачная локализация требует отдельной проверки; CSV сохранены в репозитории.

Снимок исходников: commit `3635b4f`, tag `release-2026-10-13`.

Публикация через инструменты **не подтверждена**, Studio по-прежнему показывает версию104. Скилл computer-use получил окно и accessibility tree, но снимок завершился `FrameArrived timed out`, клик File — `coordinate input geometry is unavailable`; штатные Alt+P/Alt+F не изменили состояние или версию. StudioPublishService недоступен; SavePlace в Edit отклонён: `can only be called from a server script`; CreateAssetVersionAsync ответил `not available yet`. Runtime сохранение не использовалось, поскольку оно могло бы опубликовать тестовый мир вместо исходного place.

Исходники и ассеты готовы в открытом Studio, новая погоня/сглаживание/биомы проверены в Edit. Для завершения нужна штатная команда **File → Publish to Roblox (Alt+P)** в окне Studio, затем подтверждение новой опубликованной версии.
