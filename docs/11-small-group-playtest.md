# Совместный тест Meteor Heist

Дата: 2026-10-13. Первый прогон: владелец и 3–5 тестеров, 20–30 минут.
Игра: https://www.roblox.com/games/105876478663615/

## Доступ и сбор игроков

Для закрытого теста открой Studio → File → Invite early testers, выбери друзей
и нажми Invite. Roblox позволяет пригласить до 10 early testers; доступ зависит
от возрастных ограничений и статуса trusted friends. Приглашение выполняет владелец.
Тестерам достаточно приложения Roblox, устанавливать Studio не требуется.

Альтернатива для управления доступом: Creator Dashboard → игра → Publish settings
→ Manage Audience → Manage access → Playtest. Включить Playtesters и предоставить
нужным аккаунтам право Playtest. Для игры с доступом Public можно ограничить её
друзьями через Public → Friends. Не выдавать право Edit только ради участия в игре.

Сначала владелец заходит в новый сервер, остальные присоединяются к нему.
Если игра уже публичная и нужны гарантированно отдельные участники, можно включить
бесплатные private servers: Audience → Access Settings → Allow private servers,
Requires Robux выключен; после сохранения создать сервер на странице игры и
отправить его ссылку участникам. Private servers требуют публичной игры.

Перед запуском проверить облачный MaxPlayers = 8. Ранее настройка сохранена в Hub
и зафиксирована в `reports/preprod-2026-10-12.md`; локальная Edit-сессия Studio
может показывать другое значение и не является проверкой текущей облачной настройки.

## Сценарий на 20–30 минут

| Время | Действия | Что фиксировать |
|---|---|---|
| 0–5 минут | Новые игроки самостоятельно находят метеорит, доставляют его, ставят существо | Понятность обучения, время до первой награды, ошибки или потеря яйца |
| 5–10 минут | Открыть Shop, Upgrades, Station, Collection; купить доступный предмет, проверить sold out и закрытие | Курсор возвращается в игру, кнопки нажимаются, монеты и выдача совпадают; минимум один игрок на телефоне |
| 10–15 минут | Два игрока пытаются украсть с соседних баз; проверить успешную доставку, возврат и повторную попытку | Существо не дублируется, принадлежит ровно одной базе; понятные причины отказа |
| 15–20 минут | Игрок с доступом к дальней зоне берёт метеорит и вызывает арену/погоню | Атаки начинаются, камера и движение восстанавливаются, дроны двигаются плавно |
| 20–25 минут | Выйти и снова зайти; проверить монеты, скорость, существ и купленные улучшения | Сохранения восстановились; записать ник, время и точное действие при ошибке |
| 25–30 минут | Спросить каждого, что непонятно и захотел ли бы он зайти завтра | По одному препятствию и интересному моменту от каждого |

Реальные покупки за Robux не являются обязательной частью этого теста. Можно
проверить показ цены и отмену системного окна; платёжную выдачу дополнительно
проверять отдельно. Этот прогон не заменяет нагрузочный тест на 8 игроков.

Шаблон ошибки: ник / устройство / время / зона / что нажал / ожидаемый результат /
что произошло / видео или скриншот. Результаты собрать в один список и повторно
проверить исправления теми же участниками.

## Публикация текущей сборки

Сборка меню: commit `73f5d5043e97133dd8aab957db7735fba2c73251`,
tag `modern-ui-ready-2026-10-13`. Исходники синхронизированы в Edit нужного place;
результаты 75 проверок и визуальной приёмки: `reports/modern-ui-2026-10-13.md`.

Для обновления существующего place использовать File → Publish to Roblox
(Alt+P), дождаться сообщения об успехе, затем запускать новый сервер.
Обновление опубликованной сборки и изменение аудитории — отдельные действия.

В этой сессии автопубликация недоступна: Windows capture сообщает
`FrameArrived timed out`, input — `coordinate input geometry is unavailable`,
Chrome CDP не отвечает, Studio MCP не имеет capability RobloxScript для Publish.
Пользователь выполнил штатный Publish и явно подтвердил: «Публикация завершилась
успешно». Успех публикации подтверждён пользователем; независимое чтение нового
номера опубликованной версии недоступно в этой сессии. Последнее наблюдение Edit
сообщает version125, asset metadata — Updated `2026-10-13T19:56:59Z`; эти значения
не использовать как номер новой опубликованной сборки. Следующая проверка —
запуск свежего сервера и наличие обновлённых меню в приложении Roblox.
